待驗收草稿

尚未完成教師審閱與學生對話測試。這裡是公開使用入口；完整教材維持私人，下載後透過 Claude Code 或 Codex 提問。本頁不提供聊天。

三步開始使用

第一次設定好，以後直接打開課程資料夾。

  1. 01

    下載課程資料夾

    接受 GitHub 邀請後，開啟課程資料庫，選擇 Code → Download ZIP，再解壓縮。

  2. 02

    準備 AI 工具

    安裝 Claude Code 或 Codex，並登入自己的帳號。工具費用依你使用的方案而定。

  3. 03

    打開資料夾，開始提問

    在終端機輸入 cd 加空格，拖入解壓後的資料夾並按 Enter。接著輸入 claude 或 codex，使用下方指令。

助教指令沒有載入？

確認打開的是包含 AGENT.md 的課程資料夾。也可以直接貼上這段文字：

請完整讀取本資料夾的 AGENT.md，依其中的規則與教材來源回答：我的問題是……

回到教材，核對答案

以下連結皆需先取得課程 GitHub 存取權。

  • 課務與評分歷史課務快照；日期與規則以最新公告為準。↗
  • 講義與單元依主題找到講義，核對定義、例子與推導。↗
  • 作業說明提問時附上學期、檔案代碼與題號。↗
  • 課前先備與自我檢測找出需要補強的概念，也能請助教一次問一題。↗
  • 課程概念地圖看懂概念之間的先備關係，找出回頭複習的入口。↗
  • 歷屆考試部分待補齊部分 Word 考卷公式缺漏，取得完整題目前暫停使用相關題目。↗
